# Jin Cheon Bluetooth Speaker Project

This repo contains the submission for the Bluetooth Speaker Project by Jin Cheon. The project focuses on building a responsive promotional website for a retro futurism lamp & bluetooth speaker designed by Jin Cheon.

The layout adapts across mobile, tablet, and desktop screen sizes using a mobile first approach, CSS grid, and media queries. The 3D AR model is integrated with Model Viewer and includes hotspots that load text and images from JavaScript arrays and objects. The Page also features an X-ray slider and a GreenSock scroll animation. All code is organized using SASS components and a JavaScript IIFE following class best practices.
